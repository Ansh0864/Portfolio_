# 🚀 Ansh Chauhan – Developer Portfolio

A modern, high-performance, light-theme portfolio for **Ansh Chauhan** (Full-Stack & Generative AI Engineer). Built with **React 18, Vite, Tailwind CSS, and Lucide Icons**.

Inspired by clean, minimalist developer portfolios like `jayesh-script.vercel.app`, with custom light-mode design tokens, interactive project architecture deep-dives, developer CLI playground, and comprehensive project showcases.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
Production assets are generated in `dist/`.

### 4. Deploy to Vercel / Netlify
Run:
```bash
npx vercel
```
or connect the repository directly to Vercel / GitHub Pages.
